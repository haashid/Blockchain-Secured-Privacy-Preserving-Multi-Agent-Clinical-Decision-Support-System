# Cardiac Care Guidelines
## Acute Coronary Syndrome (ACS)
For patients presenting with symptoms of acute coronary syndrome:
1. Immediate 12-lead ECG.
2. Check cardiac biomarkers (High-sensitivity Troponin).
3. Administer Aspirin 300mg unless contraindicated.
4. If ST-elevation is present (STEMI), arrange immediate primary PCI or thrombolysis.

## Heart Failure Exacerbation
For acute decompensated heart failure:
1. Assess volume status and perfusion.
2. Intravenous loop diuretics (e.g., Furosemide).
3. Consider vasodilators (e.g., Nitroglycerin) if blood pressure allows.
4. Monitor kidney function and electrolytes closely.
